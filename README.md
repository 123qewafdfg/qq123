## 这是什么

一个**在浏览器里跑**的图像 / 视频加密工具。不需要安装任何软件，打开网页就能用。

支持两种加密算法：
- **希尔伯特曲线**（Hilbert curve）—— 空间填充曲线重排像素，加密后图片像一团彩色噪点
- **分块打乱** —— 把图像切成小块随机重排，视觉效果类似拼图被打乱

## 技术栈

```
┌─────────────────────────────────────┐
│          HTML / CSS / JS            │ 单页应用
├─────────────────────────────────────┤
│     Pixi.js 8 (Canvas 渲染)         │ 视频帧实时绘制
│     GSAP 3 (动画)                   │ 交互动效
├─────────────────────────────────────┤
│     Web Worker                      │ 主线程不卡顿
│         ↓                           │
│     Rust → WASM                     │ 像素级加密运算
│   (Hilbert + Block 算法)            │
├─────────────────────────────────────┤
│     JSZip + FileSaver               │ 批量打包下载
└─────────────────────────────────────┘
```

加密核心用 **Rust** 编写，编译为 WASM，通过 Web Worker 在后台线程执行。处理大图或视频时浏览器不会卡死。

## 功能

- **🎬 视频解密** — 选择加密视频，实时解密预览播放，支持镜像输出
- **🖼️ 图片批量加密/解密** — 一次选多张图，批量处理，支持 JPG / PNG / WebP 导出
- **🔑 密钥系统** — 可设密钥，加解密需匹配
- **🔄 批量重加密** — 对已加密图片反复套娃加密，计数显示
- **📦 ZIP 打包下载** — 批量处理结果一键打包
- **🔍 在线预览** — 解密后直接在浏览器看效果，满意再下
- **🖥️ 电脑版客户端** — 提供桌面版下载（性能更好）

## 加密算法说明

### 希尔伯特曲线

基于空间填充曲线（Hilbert curve）对像素位置做二维到一维的映射，按曲线路径重排像素位置。优点是加密后像素分布均匀，不会出现明显的块状结构。

### 分块打乱

将图像分割为 W×H 的块，基于密钥生成伪随机排列，打乱块的位置。简单直观，适合对视频帧做快速加解密。
